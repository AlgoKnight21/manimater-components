# Code of conduct

Be kind, assume good faith, and keep feedback about the work, not the person. Beginners and non-programmers are welcome
here and are not expected to know the jargon. Harassment, personal attacks and discrimination are not tolerated.

Maintainers may edit or remove contributions and comments that break these rules. To report a problem, email
the address on the maintainer's GitHub profile ([@bishnt](https://github.com/bishnt)).
